# 소매전산 도메인 메모

## 주요 영역

| 영역 | 확인된 책임 |
|---|---|
| 차량 | 차량 기본정보, 현재 상태, 재고 편입 |
| 매입 | 매입 등록, 송금 요청, 매입 확정, 취소 |
| 재고 | 재고등록일, 판매부서, 악성재고 규칙 |
| 계약 | 판매 계약과 계약가 |
| 비용 | 차량별 1:N 상품화비용 |
| 손익 | 판매가, 매입총액, 상품화비용, 세금·수수료 |
| 거래정산 | 입출금 기반 정산과 지급대상 구분 |
| 권한 | 데이터 범위와 보호 필드 노출 |
| 경매연계 | 출품·평가·낙찰·재출품·반납 연계 |

## 확인된 상태 흐름

### 매입

등록 → 송금요청 → 매입확정 → 취소

### 경매

출품접수 → 평가완료 → 평가확정 → 출품확정 → 완료/완료중 → 종료

경매 결과 요청은 낙찰확정요청, 재출품, 반납으로 구분합니다.

## 명칭 메모

- 매입처 / 매수처 후보 테이블명: `RTC_BUY_VENDOR`, `RTC_SALE_VENDOR`
- 개인/법인 수수료 구분: `PERS`, `CORP`
- 날짜: 등록일, 송금요청일, 송금완납일, 재고등록일
- 후판매지점, 대리판매지점, 거래지점, 계약지점은 업무 정의를 확정한 뒤 컬럼명에 반영합니다.
